# Tests Folder

This folder is intentionally separate from application code.

## Structure
- `tests/unit/` for unit tests
- `tests/integration/` for integration tests
- `tests/e2e/` for end-to-end tests
- `tests/plans/` for sprint test planning documents

## Current Planning Artifacts
- `tests/plans/test-spec-by-sprint.md`

## Implementation Rule
Do not place test files under `apps/web` or other application folders.
